Architecture BLAS/\+TLAS Le lancé de rayons utilise deux niveaux d\textquotesingle{}arbres AABB \+:
\begin{DoxyItemize}
\item BLAS (Bottom Level) \+: un arbre AABB par maillage/liste de triangles (\mbox{\hyperlink{classObject}{Object}}), construit une seule fois qui utilise l\textquotesingle{}arbre AABB par défaut qui a un AABB\+\_\+triangle\+\_\+primitive.
\item TLAS (Top Level)\+: un arbre AABB de boîte englobantes (1 par entité de la scène), reconstruit pour chaque scène. Il utilise une primitive custom un Iso\+\_\+\+Cuboid\+\_\+3 qui est une boite 3D dont les faces sont parralèles aux X,Y,Z. Bbox\+\_\+3 est juste du stockage et n\textquotesingle{}est pas forcément parralèle aux axes X, Y, Z du repère monde alors que cette structure peut intersecter un rayon. Pour être acceptée par CGAL comme primitive custom, on a créé une classe qui satisfait le concept de AABBprimitive définie dans les exemples \+: \href{https://doc.cgal.org/latest/AABB_tree/AABB_tree_2AABB_custom_example_8cpp-example.html}{\texttt{ https\+://doc.\+cgal.\+org/latest/\+AABB\+\_\+tree/\+AABB\+\_\+tree\+\_\+2\+AABB\+\_\+custom\+\_\+example\+\_\+8cpp-\/example.\+html}} \href{https://doc.cgal.org/latest/AABB_tree/AABB_tree_2AABB_polyhedron_facet_intersection_example_8cpp-example.html}{\texttt{ https\+://doc.\+cgal.\+org/latest/\+AABB\+\_\+tree/\+AABB\+\_\+tree\+\_\+2\+AABB\+\_\+polyhedron\+\_\+facet\+\_\+intersection\+\_\+example\+\_\+8cpp-\/example.\+html}} La primitive doit fournir \+:
\item Id \+: type identifiant
\item Point \+: type point pour le calcul du referentiel (placé au milieu de la boite)
\item Datum \+: type geometrique interserctable avec un rayon
\item id() \+: retourne l\textquotesingle{}Id
\item datum() \+: retourne l\textquotesingle{}objet de type Datum
\item reference\+\_\+point()\+: retourne le point représentatif
