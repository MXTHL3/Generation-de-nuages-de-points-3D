Ce projet est une application dédiée à l\textquotesingle{}analyse de nuage de points autour de deux parties \+:
\begin{DoxyItemize}
\item la génération et la visualisation de nuages de points via le scan par lidar virtuel d\textquotesingle{}une scène modifiable.
\item l\textquotesingle{}entrainement d\textquotesingle{}un modèle de reconnaissance qui a pour but de reconnaitre des sihouettes humaines au sein de nuages de points.
